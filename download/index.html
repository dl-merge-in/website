DL-MERGE-IN DESKTOP v1.2.3

Windows デスクトップ版

Chromeを標準対応とし、セットアップ時の選択でMicrosoft Edgeにも対応します。セットアップ後、ブラウザで拡張機能を一度手動で読み込みます。

Setup.exe をダウンロード ↓

バージョン1.1.0にはアプリ内更新機能がないため、v1.2.3へ移行するときだけこのセットアップを実行してください。v1.2.3以降の対応リリースは、アプリ内の「更新」から更新できます。

ファイルを確認する

ダウンロード元が正規の GitHub Release であること、ファイル名とバージョンが一致することを確認してください。ファイルは現在コード署名されていません。

対象ファイル
DL-Merge-In-Desktop-Setup-1.2.3.exe

SHA-256

F587B10D7E4C61BD6D4C48CD9A636A05C7FA657075C8AD5AA0E91A78B6C93368

Windows PowerShellで確認する場合は、次を実行し、表示された Hash が上記と完全に一致するかを確認します。

Get-FileHash -Algorithm SHA256 "$env:USERPROFILE\Downloads\DL-Merge-In-Desktop-Setup-1.2.3.exe"

未署名の配布について

この配布ファイルにはコード署名がありません。そのためWindowsでSmartScreenまたは「不明な発行元」に関する警告が表示される場合があります。

警告が表示された場合は、先に進む前にダウンロード元、ファイル名、バージョン、SHA-256を確認してください。確認できない場合や少しでも不安がある場合は、実行せずにReleaseページと本ページの情報を再確認してください。

インストール後の流れ

  1. Setup.exeを実行します。
  2. 案内に沿って、Chromeまたは選択したEdgeで拡張機能を手動で読み込みます。
  3. 保存したいメディアのあるページを開き、Detectタブから候補を選びます。

詳しい操作はセットアップガイドをご確認ください。
