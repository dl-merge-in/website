対応サービス例

対応サービスの
例と注意事項

デスクトップ版とChromeウェブストア版（CWS版）では、対応範囲が異なります。対応状況はページ構成、配信方式、地域、外部サービス側の変更によっても変わります。

デスクトップ版とCWS版の違い

WINDOWS DESKTOP

デスクトップ版

Setup.exeで導入し、ローカル処理サーバーと連携するフル版です。YouTubeのダウンロードに対応しています。

CHROME WEB STORE

CWS版

Chromeウェブストア向けのクライアント単体版です。現在は公開に向けて準備・審査中です。ストアの方針に合わせ、YouTubeを含む一部サイトは対象外です。

デスクトップ版の対応例

個別対応と汎用検出により、動画・音声の保存候補を探します。現在の例として、YouTube、ニコニコ、TVer、Abema、Twitch、Vimeo、TikTok、X、Instagramなどがあります。

yt-dlpに対応する多数のサービスに加え、yt-dlpがサイトとして対応していないページでも、独自の汎用検出が候補を見つける場合があります。

CWS版の対応例

ニコニコ、TikTok、Instagram、X、Redditなどが対応例です。一方、YouTube、TVer、Abema、Twitch、VimeoなどはCWS版の対象外です。これらを利用する場合はデスクトップ版をご検討ください。

CWS版は現在、公開に向けて準備・審査中です。ストアでの公開後も、CWS版とデスクトップ版は同じ対応範囲にはなりません。どちらの版でも、すべてのページ、配信方式、コンテンツでの動作を保証するものではありません。

機能上の補足

画質・形式・コーデックの選択、動画と音声の結合、キュー管理、一時停止・再開、速度制限に対応しています。YouTubeの字幕は、利用可能な場合に別ファイルとして保存できます。

DRMで保護されたコンテンツは対象外です。保存できるかどうかは、対象ページの配信方式や権利設定によって異なります。

商標・利用上の注意

ここに挙げたサービス名は、対応状況を説明するための例示です。各名称および商標はそれぞれの権利者に帰属します。DL-Merge-Inは各サービスと提携・承認・推奨関係にあるものではありません。

コンテンツの保存・利用にあたっては、各サービスの利用規約、コンテンツ提供者の条件、適用法令を確認してください。詳しくは利用条件・免責・プライバシーをご確認ください。
